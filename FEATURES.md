# ✨ Features Overview

## 🎯 Core Features

### 1. Interactive Merkle Tree Visualization
**What it does**: Displays all your projects as leaves in a cryptographic tree structure.

**How it works**:
- Each project is hashed using SHA-256
- Parent nodes combine child hashes
- Root hash represents your entire portfolio
- Click any project to see details
- Path from leaf to root highlights

**Why it's cool**: Real blockchain data structure, not a simulation!

---

### 2. Tamper Demonstration
**What it does**: Shows how blockchain ensures data integrity.

**How to use**:
1. Click "Try Tamper Demo" button
2. Click any project card
3. Watch the hash invalidation propagate up the tree (turns red)
4. Click "Re-mine Chain" to recalculate and restore validity

**Why it's cool**: Visually demonstrates immutability—a core blockchain principle!

---

### 3. Real Cryptographic Hashing
**What it does**: Uses native Web Crypto API for authentic SHA-256 hashing.

**Technical details**:
- No fake hashes or simulations
- Real `crypto.subtle.digest()` calls
- Proper Merkle Tree algorithms
- Verifiable cryptographic operations

**Why it's cool**: Shows deep technical understanding, not just visual effects!
