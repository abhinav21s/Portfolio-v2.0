# 👋 START HERE!

Welcome to your Merkle Tree Portfolio! This is your starting point.

## 🎯 What is This?

A premium, blockchain-themed portfolio that represents your professional identity as a **Merkle Tree**. Every project is a leaf, and the root hash symbolizes your complete professional identity.

## ⚡ Quick Start (3 Commands)

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev

# 3. Open http://localhost:3000 in your browser
```

That's it! Your portfolio is now running locally.

## 📝 Next: Customize Your Content

Open this file and update YOUR information:

This ONE file contains:
- ✏️ Your name, title, and bio
- 💼 Your projects (become tree leaves)
- 🛠️ Your skills
